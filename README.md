## ✨ 核心功能与工作流

### 1. 🪄 创成式填充（Generative Fill / 局部重绘）
* **完美贴合 PS 习惯**：
  1. 使用 Photoshop 的**套索工具 (L)**、**矩形选框 (M)** 或**对象选择工具**圈出你想修改/消除/新增的区域。
  2. 在插件面板输入指令（如：*“移除路人”*、*“把衣服换成黑色皮夹克”*、*“在草地上放一只柯基”*）。
  3. 点击 **立即执行创成式填充**。
* **智能图层与自动蒙版**：
  * AI 结合全图光影、透视与边缘自然补全；
  * 自动将新图层置入画板，并**自动附加选区图层蒙版**！原图其他区域 100% 像素级保留，你随时可以在 PS 图层面板使用黑白画笔对边缘做羽化和精修。

### 2. 🎨 全新文生图（Text-to-Image）
* 支持直接从 0 生成高清创意画面并置入新画板。
* 支持 1K / 2K / 4K 分辨率，以及 `1:1`、`16:9`、`9:16`、`4:3`、`3:2` 等主流比例。
* 具备极强的图内英文字体排版与写实因果渲染能力。

## 🚀 插件加载与使用步骤（只需 3 步）

### 第一步：启动 Photoshop
打开你的 Adobe Photoshop，并打开任意一张你想修的图片（或新建画布）。

### 第二步：在 UXP Developer Tool 中加载插件
1. 启动 **Adobe UXP Developer Tool**（确保右上角显示 Photoshop 为绿色 **Connected**）。
2. 点击右上角 **Add Plugin** 按钮。
3. 选中本项目文件夹中的 `manifest.json`。
4. 在列表中找到 **Gemini AI Generator**，点击右侧的 **•••** 按钮，选择 **Load**。

### 第三步：在 Photoshop 中使用创成式填充
1. 切回 Photoshop，点击顶部菜单栏：**Plugins（增效工具）** -> **Gemini AI 生图**，侧边栏弹出面板。
2. 填入你的 **Gemini API Key**（插件自动记住，下次无需重复输入）。
3. 用套索工具在你的图片上圈出想要修改的区域。
4. 输入提示词（例如：`将背景杂乱的电线杆消除，融入蔚蓝天空`），点击 **“立即执行创成式填充”**。
5. 片刻后，新图层便会自动贴合在你的画布上，并自带选区蒙版！
